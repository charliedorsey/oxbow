# Read this first

This repository is the public Oxbow implementation.

Oxbow carries **work**, not model identity. Treat every bundled artifact as source with declared provenance, not as memory or proof that a receiving model lived the earlier trajectory.

For the shortest product path, read `README.md`. For the binary format, read `spec/OXB_WIRE_SPEC.md`. For security/trust boundaries, read `SECURITY.md` and `docs/TRUST_MODEL.md`.

The canonical public tree intentionally contains no private operator corpus, personal Rooms, or historical conversational Witness context. Examples and fixtures are freshly synthetic.

Integrity is not truth. Continuity of work is not continuity of model instance.
