# Read first

This directory is an **Oxbow handoff** for **Tiny relay demo**. It is meant to help a fresh AI instance or human reader pick up existing work without pretending to have lived the earlier trajectory.

## Boundary

- Treat files in this handoff as **source**, not memory.
- Do not claim continuity with a prior model instance.
- Preserve distinctions between reported facts, operator-authored state, inference, and open questions.
- Verification can establish that bytes arrived intact. It cannot establish that the contents are factually true.

## First actions

1. If you received an `.oxb.py`, verify it before relying on it: `python HANDOFF.oxb.py --verify`.
2. Read `START_HERE.md`.
3. Read `HANDOFF.md` for the current working state.
4. Pull deeper corpus material only as the task requires. Do not inventory everything unless the task calls for it.

**Carry the work, not the model.**
