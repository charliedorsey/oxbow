# Prebuilt Oxbow bundles

Want to hand Oxbow to a model or inspect it without cloning, installing, or packing the repository first? Download one of these committed self-extracting `.oxb.py` bundles.

- [`oxbow-tiny.oxb.py`](oxbow-tiny.oxb.py) — smallest orientation bundle: front-door docs, trust/continuity guidance, Witness v2 format/schema, and the synthetic tiny-handoff example.
- [`oxbow-standard.oxb.py`](oxbow-standard.oxb.py) — **recommended default**: public docs, wire spec, package source, examples, integrations, and project metadata, without development tests/fixtures/tooling.
- [`oxbow-full.oxb.py`](oxbow-full.oxb.py) — all tracked public repository files except `prebuilt/` itself; intended for development, audit, or full-repository model handoff.

A simple model handoff is:

> Read this Oxbow bundle. Start with `PREBUILT_PROFILE.md` and `START_HERE.md`.

The wrapper itself needs only Python for local read-only use:

```bash
python3 oxbow-standard.oxb.py --verify
python3 oxbow-standard.oxb.py --info
python3 oxbow-standard.oxb.py --ls
python3 oxbow-standard.oxb.py --cat PREBUILT_PROFILE.md
python3 oxbow-standard.oxb.py --tour
```

Extraction is explicit and only targets a new or empty directory:

```bash
python3 oxbow-standard.oxb.py --extract unpacked-oxbow
```

## Trust boundary

These files are executable Python wrappers around inert Oxbow payloads. Payload verification checks the bounded Oxbow wire format, exact manifest integrity, and handoff conformance. It does **not** authenticate arbitrary Python surrounding the payload.

For a wrapper you do not already trust, prefer a trusted local Oxbow installation to inspect the embedded payload without executing the wrapper source:

```bash
oxbow verify prebuilt/oxbow-standard.oxb.py
oxbow ls prebuilt/oxbow-standard.oxb.py
oxbow cat prebuilt/oxbow-standard.oxb.py PREBUILT_PROFILE.md
```

`SHA256SUMS` is a reproducibility/transport convenience, not an independent identity system. A hash obtained from the same untrusted channel as the file does not authenticate the file.

## Rebuild

The committed artifacts are generated by one script:

```bash
python3 tools/build_prebuilt.py
```

Release/CI checks can require byte-for-byte reproducibility:

```bash
python3 tools/build_prebuilt.py --check
```

The generator reads tracked repository paths rather than sweeping the working tree, so an unrelated untracked note, `.env`, or scratch file cannot silently enter a prebuilt bundle. The `full` profile explicitly excludes `prebuilt/` to prevent recursive self-bundling.
