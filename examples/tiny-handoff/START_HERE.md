# Start here

Use this order unless the task itself gives you a better reason not to:

1. `READ_FIRST.md` — boundary and trust posture.
2. `HANDOFF.md` — current purpose, state, decisions, and open questions.
3. The specific source files named by `HANDOFF.md` or by the current task.
4. `BUNDLE_LAYOUT.md` if you need to understand the object itself.
5. `witness/README.md` only if you are asked to leave a portable session record.

The whole corpus does not deserve equal attention on every turn. Orient first, then read what the work requires.
